# Siaka Phones - Premium Mobile E-Commerce App

A modern, responsive mobile-first phone shop application for **Siaka Phones** built with HTML5, CSS3, and modern JavaScript.

## 📱 Features & Included Screens (All 14 Pages)
1. **Onboarding**: Welcome hero screen with feature highlights and quick navigation.
2. **Login / Register**: Clean authentication interface with social logins and password toggles.
3. **Home**: Search bar, hero promo banner (*"Discover the Latest Smartphones"*), brand filters (Apple, Samsung, Google, OnePlus, Xiaomi), 3-column Featured Phones grid, 4 value proposition badges, and 5-tab bottom navigation dock.
4. **Search**: Search header with clear & filter tools, category chips, and live results grid.
5. **Categories**: Multi-category grid (Flagships, Foldables, Wireless Audio, Cases, Chargers, Smartwatches).
6. **Product Details**: Image gallery with vertical thumbnail strip, storage selectors (128GB, 256GB, 512GB, 1TB), color swatches, Add to Cart & Buy Now buttons, delivery ETA countdown, and product highlights.
7. **Wishlist**: Saved items with in-stock indicators and move-to-cart actions.
8. **Cart**: 3-item cart with quantity steppers, free shipping progress bar, tax/subtotal calculation, and Proceed to Checkout button.
9. **Checkout - Shipping**: Step 1 stepper, address selection cards with default badge, new address button, and shipping speed selector (Standard, Expedited, Overnight).
10. **Checkout - Payment**: Step 2 stepper, Credit/Debit card form (Visa, Mastercard, PayPal, Apple Pay, Google Pay) with security fields.
11. **Checkout - Review Order**: Step 3 stepper, delivery and payment summary cards, promo code input (`SIAKA10`), and place order button.
12. **Order Confirmation**: Animated green checkmark, order ID `#SP-89421`, delivery estimate, and tracking shortcut.
13. **Order Tracking**: Live status badge (*"Out for Delivery"*), courier driver info, and 5-step delivery timeline.
14. **Profile**: VIP member header, orders/wishlist counters, account menu, and settings.

## 🚀 How to Run Locally

### Option 1: Direct Browser
Open `index.html` directly in any modern web browser.

### Option 2: PowerShell Web Server
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
Open [http://localhost:3000/](http://localhost:3000/) in your browser.
